# 🌌 CuánticaVital: Trayectoria Interactiva de Computación Cuántica

Plataforma educativa web, libre y gratuita, diseñada para mostrar cómo puede evolucionar la educación en computación cuántica a lo largo de toda la vida (*Lifelong Learning*), desde la infancia hasta la edad adulta y profesional.

---

### 🎯 Características Principales
- **4 Etapas Educativas Interactivas:**
  1. **Infancia (6-12 años):** Intuición, juego y simulador visual de superposición de fotones.
  2. **Adolescencia (13-18 años):** Conexión STEM, qubits y laboratorio de circuitos con compuertas lógicas (Hadamard).
  3. **Universidad / Profesional (19-35 años):** Inmersión técnica, álgebra lineal y consola de simulación de código Python (Qiskit).
  4. **Edad Adulta y Madurez (36+ años):** Estrategia, evaluación de amenazas (Algoritmo de Shor) y ciberseguridad post-cuántica (PQC).
- **Interfaz Moderna y Adaptativa:** Diseño estilo panel de control científico con modo oscuro/claro y componentes interactivos integrados.
- **100% Autocontenido:** Desarrollado en un único archivo `index.html` optimizado con Tailwind CSS y JavaScript nativo.
